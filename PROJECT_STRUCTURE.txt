API ENDPOINTS SUMMARY
=====================

Auth:
  POST   /auth/apple
  GET    /user/me
  PATCH  /user/me

Friends:
  GET    /friends
  POST   /friends
  DELETE /friends/{id}
  GET    /friends/requests
  POST   /friends/requests/{id}/accept
  POST   /friends/requests/{id}/reject

Sessions:
  POST   /sessions/start
  POST   /sessions/end
  GET    /sessions/active

Unlock Requests:
  POST   /unlock-requests
  GET    /unlock-requests/pending
  POST   /unlock-requests/{id}/approve
  POST   /unlock-requests/{id}/reject

Proofs:
  POST   /proofs (multipart)
  GET    /proofs/{id}
  GET    /proofs/user/{id}

Notifications:
  POST   /notifications/device-token


ARCHITECTURE PATTERNS
=====================

- MVVM Architecture (ViewModels + Views)
- Protocol-Oriented Design (Service Protocols)
- Feature-Based Organization
- Dependency Injection (Service Singletons)
- App Group Storage (App ↔ Extension Communication)
- Screen Time API Integration
- SwiftUI Views
- Async/Await Networking
